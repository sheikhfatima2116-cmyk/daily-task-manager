# Daily Task Manager 📝

A simple and responsive Daily Task Manager built with React. This application helps users organize their daily activities by adding, completing, and deleting tasks.

## ✨ Features

* Add new tasks
* Mark tasks as completed using checkboxes
* Delete tasks
* View total, completed, and pending task counts
* Save tasks in browser LocalStorage
* Responsive user interface

## 🛠️ Technologies Used

* React
* JavaScript
* HTML / JSX
* CSS
* Vite
* LocalStorage

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Open the project folder

```bash
cd daily-task-manager
```

### 3. Install dependencies

```bash
npm install
```

### 4. Run the application

```bash
npm run dev
```

Open the local URL shown in your terminal.
